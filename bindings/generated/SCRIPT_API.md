# Script API reference

GENERATED by `python3 -m tools.bindgen` - DO NOT EDIT.

Every function callable from Lua and Ruby, with the signature as the
**script** sees it. That is not always the C signature:

- A `(const void *data, size_t len)` pair collapses into **one**
  string argument, so later parameters shift left. For example
  `Grapple_CreateGui(renderer, font_data, font_len, font_size)` is
  `GrappleC.CreateGui(renderer, font_data, font_size)` — passing a
  spurious length argument silently lands in `font_size`.
- Pure out-parameters are **not** arguments; they come back as extra
  return values, after the function's own return value.
- In/out parameters are passed *and* returned.
- `nk_bool` crosses as a real boolean; `0` is truthy in both
  languages, so test truthiness, never `== 1`.

Ruby uses the same names and order (`SDL.CreateWindow`), with
constants as module constants (`SDL::INIT_VIDEO`) and multiple
returns as an array.
