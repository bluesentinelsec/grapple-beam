GRAPPLE-BEAM CLI REFERENCE
==========================

This reference describes current main (settings introduced after v0.9.0).
Run grapple-beam --help-all to inspect the executable you are actually using.
The typed settings come from engine/src/settings_schema.inc.
See cli-implementation.md (cli-implementation.html on the docs site) for
project layout, precedence, saving, recovery, and runtime capability behavior.

INVOCATION

  grapple-beam [options] [project-directory|script.lua|script.rb] [-- game-args...]
  grapple-beam repl --language lua|ruby
  grapple-beam eval --language lua|ruby --code SOURCE [-- args...]

No path means project discovery in the current directory. No implicit REPL.
All engine options precede the project; trailing tokens belong to the game.
CLI file paths use the invocation directory; game paths use the project root.
Use --key=value or --key value. Scalar repeats take the last value; boolean
settings require on|off. --config and --config-script are repeatable overlays.

PRECEDENCE (LOW TO HIGH)

  Engine/inline game defaults
  Media config.toml, then project config.toml
  Project config.lua or config.rb
  Player config.toml, then player config.lua or config.rb
  Each --config FILE, then each --config-script FILE
  Individual CLI settings (--quality expands before individual fields)

Recovery flags are mutually exclusive and reject explicit config files:
  --default-settings skips player sources for one launch.
  --reset-settings backs up recognized player configuration, preserving saves.
  --safe-mode skips all files/scripts, uses windowed software rendering at
    1280x720, primary display, low budgets, effects/shadows off, 60 FPS.
Individual CLI settings still override recovery presets. No automatic saving.
--reset-settings --print-settings previews without moving player files.

IMPLEMENTED OPTIONS (grapple-beam --help-all)

Run a Lua/Ruby project or script. Engine options precede the project; --
introduces game arguments.


grapple-beam [OPTIONS]


OPTIONS:
  -h,     --help              Print this help message and exit
  -V,     --version           Display program version information and exit
          --help-all          Include registered settings and advanced options
  -l,     --language TEXT:{lua,ruby}
                              Language inferred from project or entrypoint
          --list-backends     Probe concrete renderers and report versions
          --list-displays     List displays without launching a project
          --list-display-modes
                              List exclusive modes for --display
          --print-settings    Resolve requested settings and sources, then exit
          --safe-mode         Bypass configuration scripts/files; use recovery defaults
          --default-settings  Ignore player settings for this launch
          --reset-settings    Back up player settings and restore game defaults
          --config TEXT       Explicit TOML overlay (repeatable)
          --config-script TEXT
                              Explicit Lua/Ruby settings overlay (repeatable)
          --quality TEXT:{low,medium,high}
                              Preset: low=.75 scale/no FXAA; medium/high=1 scale/FXAA; matching
                              budgets
          --set TEXT          Advanced typed override; keys listed below
          --window-mode windowed|fullscreen-borderless|fullscreen-exclusive
                              display.window_mode; inherited default fullscreen-borderless
          --window-size WIDTHxHEIGHT

          --display primary|zero-based index

                              display.refresh_rate; inherited default desktop

Advanced keys (use --set KEY=VALUE):
engine.title (text)
engine.design_size (WIDTHxHEIGHT)
engine.tick_rate (1..1000)
engine.max_steps_per_frame (1..1000)
engine.max_frame_seconds (1e-06..10)
engine.interpolation (lerp|none|extrapolate)

Examples:
grapple-beam --window-mode windowed .
grapple-beam --config player.toml ./game -- --level forest


MIGRATION

  --fullscreen / --windowed -> --window-mode VALUE
  --no-vsync -> --vsync off
  --with-default-settings -> --default-settings
  --with-safe-mode -> --safe-mode
  Numeric FPS sentinels -> --max-fps display|unlimited
  Top-level -e -> eval --language LANGUAGE --code SOURCE
  Implicit REPL -> repl --language LANGUAGE
  --media-password -> encrypted media provisioning in the embedding API

EXIT STATUS

  0: successful execution, help, or diagnostics
  2: usage/configuration validation failure
  1: execution/runtime failure
