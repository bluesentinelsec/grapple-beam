# Troubleshooting

Keep all extracted files together. Missing or invalid media causes startup to fail instead of silently substituting placeholder art. Run from a terminal for errors. If display settings prevent play, launch with `--safe-mode`; restore player defaults with `--reset-settings`. Exclusive fullscreen availability depends on the OS/display; use borderless or windowed when a mode switch is unavailable. Unsigned macOS/Windows apps may need platform trust/signing steps before general distribution. Linux requires the runtime baseline described in the release notes.
