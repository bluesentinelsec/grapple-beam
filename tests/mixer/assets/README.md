# Audio test corpus

Except for the `c64-composition*` fixtures, the files here are **synthesized**
by `scripts/gen_test_audio.py` — a
deterministic chiptune music loop (square lead + triangle bass) and three
retro sound effects (laser sweep, noise-burst explosion, coin blip), plus a
hand-assembled Standard MIDI File. No external recordings; no third-party
licenses. Regenerate with:

```bash
python3 scripts/gen_test_audio.py    # WAVs + MIDI directly; ogg/mp3/flac/
                                     # aiff/au/voc encoded via ffmpeg
```

The same files back the local demo and the format decode tests
(`tests/mixer/mixer_test.cpp`).

`c64-composition.mid` is the user-provided Guitar Pro export supplied for the
streaming chiptune implementation (2026-09-11), copied without modification.
It is not generated by the script above. It has a conductor track and four
instrument parts: Jazz Guitar (20 notes), Steel Guitar (15 chord notes),
Electric Bass (20 notes), and Drumkit (32 notes). Timing: type 1, 480 PPQN,
120 BPM, 9600 ticks / 10 seconds. It contains no triplets; synthetic tests
separately cover triplets, tempo changes, and leading rests. The composition
is a regression fixture, not part of the installed SDK or preset bank.

`c64-composition-named.mid` is the user's subsequent Guitar Pro export from the
same date, copied without modification. The four instrument names are `melody`,
`harmony`, `bass`, and `percussion`. It verifies automatic role mapping without
track-index overrides, including the default wet harmony effects.

`c64-composition-named.xml` is the matching MusicXML 2.0 partwise export from
Guitar Pro 8.1.5, copied without modification. It has the same four named parts
and five 4/4 bars at 120 BPM. The file contains 142 note entries: the pitched
parts appear on both standard-notation and tablature staves, while percussion
appears once. The intended performance contains 87 notes, as in the MIDI.
Staff-specific octave transpositions, percussion instrument IDs, and differing
division values make it a useful importer regression fixture. It contains no
tuplets; separate fixtures are needed to exercise those rhythms.

The author supplied these compositions and authorized committing the MIDI and
MusicXML exports for repository demos and test data on 2026-09-11. They are
source fixtures, not generated audio or third-party recordings. Do not regenerate
or reformat these exports when changing the synthesized corpus.
